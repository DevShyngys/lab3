
========================================================================
ПРОВЕРКА 1. Оба сервиса работают: создание товара и заказа
========================================================================
Сервис A (каталог): http://127.0.0.1:5001
Сервис B (заказы):  http://127.0.0.1:5002
Таймаут запросов B → A: 2.0 с

$ curl -i -X POST http://127.0.0.1:5001/products \
       -H 'Content-Type: application/json' \
       -d '{"name": "Мышь", "price": 5000}'
HTTP/1.1 201 CREATED
Content-Type: application/json
Location: /products/1

{
  "id": 1,
  "name": "Мышь",
  "price": 5000
}

$ curl -i -X POST http://127.0.0.1:5002/orders \
       -H 'Content-Type: application/json' \
       -d '{"product_id": 1, "quantity": 3}'
HTTP/1.1 201 CREATED
Content-Type: application/json
Location: /orders/1

{
  "id": 1,
  "product_id": 1,
  "name": "Мышь",
  "price": 5000,
  "quantity": 3,
  "total": 15000
}


========================================================================
Останавливаем сервис A (каталог)
========================================================================
Сервис A остановлен. Сервис B продолжает работать.
$ curl -i http://127.0.0.1:5002/health
HTTP/1.1 200 OK
Content-Type: application/json

{
  "service": "orders",
  "status": "ok",
  "catalog_url": "http://127.0.0.1:5001",
  "timeout": 2.0
}


========================================================================
ПРОВЕРКА 2. Каталог выключен: создание заказа возвращает 503
========================================================================
$ curl -i -X POST http://127.0.0.1:5002/orders \
       -H 'Content-Type: application/json' \
       -d '{"product_id": 1, "quantity": 2}'
HTTP/1.1 503 SERVICE UNAVAILABLE
Content-Type: application/json

{
  "error": "catalog_unavailable",
  "message": "Сервис каталога недоступен: нет соединения с каталогом: ConnectionError"
}

Сервис B не упал — отвечает на следующие запросы.

========================================================================
ПРОВЕРКА 3. Каталог выключен: чтение заказа возвращает 200
========================================================================
$ curl -i http://127.0.0.1:5002/orders/1
HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": 1,
  "product_id": 1,
  "name": "Мышь",
  "price": 5000,
  "quantity": 3,
  "total": 15000
}

Название и цена взяты из самого заказа, обращения к A не было.

========================================================================
Дополнительно: несуществующий товар при работающем каталоге
========================================================================
$ curl -i -X POST http://127.0.0.1:5002/orders \
       -H 'Content-Type: application/json' \
       -d '{"product_id": 999, "quantity": 1}'
HTTP/1.1 404 NOT FOUND
Content-Type: application/json

{
  "error": "product_not_found",
  "message": "товар с id=999 отсутствует в каталоге"
}

Каталог доступен, но товара нет — это 404, а не 503.

Оба сервиса остановлены.
